Google OAuth sin configurar

Error 401: invalid_client — falta el Client ID

"The OAuth client was not found" significa que el Client ID no está registrado en Google Cloud Console. Configúralo en 4 pasos:

  1. Entra a console.cloud.google.com → APIs y servicios → Credenciales
  2. Si no tienes: Crear credenciales → ID de cliente de OAuth → Aplicación web
  3. En Orígenes de JavaScript autorizados agrega el origen de esta página (ej.: http://localhost:8000 o tu dominio https)
  4. Copia el ID de cliente (termina en .apps.googleusercontent.com) y pégalo abajo → Guardar

Se guarda solo en tu navegador (localStorage). Para producción, colócalo directamente en la constante GOOGLE_CLIENT_ID_PLACEHOLDER de index.html.

Descargar Aplicación APK

Convierte esta Web App en una APK nativa para Android compilando mediante **Apache Cordova** o **Capacitor**.

1. npm install -g cordova

2. cordova create GomiColicApp

3. cordova platform add android

4. cordova build android --release
